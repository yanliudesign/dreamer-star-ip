怎么用这个页面？

1. 扫一遍找到你想要的动作，记下编号（比如 C3）。
2. 打开 action-library.md，找到对应卡片，复制它的"动作段"。
3. 打开 prompt-template.md（主 prompt 骨架），把"动作段"塞到 Single visual concept 和 Composition 部分。
4. 复制完整 prompt → ChatGPT image / Nano Banana / MJ 里跑图。

更懒的方式：直接告诉 Claude ——
  "用小星妍 skill，动作 C3，给我配一张图，主题是复利"
Claude 会自动拼装完整 prompt 给你。
